# Changelog

本项目遵循语义化版本。正式发布前的变更记录在 `Unreleased` 下维护。

## [Unreleased]

### Added

- Windows/Android 统一聊天与文件传输界面。
- 可信设备配对、控制长连接、自动重连与解除配对。
- SQLite 消息和传输任务持久化、离线历史与本地设置。
- 文件偏移续传、`.part` 恢复、SHA-256 校验和校验失败重试。
- 摄像头通话、音频、屏幕共享、媒体超时和画面清理。
- Android SAF、前台服务、WakeLock、MulticastLock 与网络变化恢复。
- HMAC-SHA256 控制、文件和媒体认证。
- Windows 自包含部署、Android APK/AAB 构建与签名验证脚本。
- 7 项桌面自动测试及跨设备人工验收矩阵。

### Changed

- UI 重构为现代响应式聊天布局，并统一桌面与移动端交互。
- Android 构建基线升级到 API 36、AGP 8.9.1、Gradle 8.11.1 与 JDK 17。

### Security

- 不再仅凭广播设备 ID 或来源 IP 授予控制、文件和媒体权限。
- 升级前缺少认证密钥的旧可信记录需重新配对，历史消息和已完成文件保留。

## [0.1.0] - 2026-09-22

- 首个作品集候选版本；正式标签应在跨设备验收完成后创建。
