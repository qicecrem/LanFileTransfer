# 网络集成测试

`transfermanager_integration_test` 会在同一进程中启动两个具有独立身份、设置、任务数据库和接收目录的 `TransferManager`。双方通过真实的本机 TCP socket 通信，不替换协议收发层。

当前覆盖以下链路：

1. 首次配对被拒绝后，发起端回到 `unpaired`。
2. 再次配对并接受后，双方都建立可用的控制会话。
3. 主动中断控制连接后，双方自动重连并收敛到唯一会话。
4. 重连完成后文本消息能够正常送达。
5. 发送 64 MB 文件时中断接收连接，重试后必须从非零偏移继续。
6. 续传完成后同时检查双方 `verified` 状态、文件大小和 SHA-256。
7. 双方解除配对后都回到 `unpaired`。

测试使用临时目录，不读取或修改用户的可信设备、聊天记录和传输任务。

通过项目构建脚本运行全部桌面测试：

```powershell
.\build-desktop.ps1 -QtRoot D:\QT\6.8.3\mingw_64 -MinGwBin D:\QT\Tools\mingw1310_64\bin
```

集成测试设有 60 秒超时。失败时会输出失败阶段、双方状态迁移以及当前控制会话方向，便于定位偶发网络竞态。
