## 本轮发现的问题

- Android SAF 文件发送的大小和 SHA-256 正确，但部分 DocumentsUI URI 的显示名回退为 `document:<id>`，没有保留原始文件名；本轮复现为 `landrop-device-test.pdf` 显示成 `document:1000245611`。
- OnePlus/ColorOS 相机 HAL 在通话时持续输出 `oppo_imx set wrong dolnum:-1`，未造成崩溃或停帧，后续应在更多设备上确认是否仅为厂商日志噪声。
