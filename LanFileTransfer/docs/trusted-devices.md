# 可信设备管理

设置页中的“管理可信设备”展示已经完成配对并保存在本机的设备。列表数据由 `TransferManager` 的连接状态机提供，不依赖设备当前是否仍出现在附近发现列表中。

每条记录包含：

- 设备名称和设备 ID；
- 最近一次连接地址；
- 在线、重连中或离线状态；
- 最后一次确认在线的时间。

解除配对需要二次确认。确认后会：

1. 删除本机保存的可信关系；
2. 停止该设备的控制连接和活动文件连接；
3. 取消双方之间尚未完成的本地传输任务；
4. 立即撤销消息、文件和媒体连接授权。

聊天历史和已经接收完成的文件不会删除。对方设备如果仍保存本机的可信关系，再次连接时本机仍会按新的配对请求处理，不会自动恢复授权。
